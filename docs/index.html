Forward pass.
The rule

Add the block's output to the state two layers back

An ordinary residual block, s⁺ = s + f(s), cannot be undone: recovering s needs f(s). The reversible family evaluates the block at the state in between, which the backward pass already holds. So each layer's input can be rebuilt from the two states above it.

One rule, three integrators

Gal, Eliasof, Turek, Ascher, Treister & Haber, 2025 (arXiv 2512.02056)
sk+1 = α·sk−1 + β·sk + γ·fk(sk)
sk−1 = ( sk+1 − β·sk − γ·fk(sk) ) / α

“Euler” enters in two places. A two-step rule needs a second starting state, and the Euler start makes it with one ordinary residual step: s₁ = s₀ + h·f₀(s₀). The alternative, no-kick, uses s₁ = s₀. The blend rule also behaves like forward Euler in expectation (paper §3.2).

Why |α| must be 1: run the recurrence backwards

Roots of z² = βz + α. The backward pass multiplies rounding error by |1/z| per layer.

1 · RECOMPUTEfx = f_k(s[k])

Run block k again, with a graph, at the state the backward pass already holds.

2 · REBUILDs[k-1] = (s[k+1] − β·s[k] − γ·fx) / α

Read the rule right to left to recover the state below. Nothing was stored for it.

3 · BACKPROPḡ[k] += γ·Jᵀḡ[k+1] + β·ḡ[k+1]

Push the adjoint through the block once, collecting the weight gradients on the way.

4 · DROPḡ[k-1] = α·ḡ[k+1]; k ← k−1

Free the block's graph and s[k+1]. Memory never holds more than one layer's work.

How exact is “exact” in bf16?

The custom backward matches autograd to 1e-9 in float64. In training the blocks run in bf16, so each rebuilt state carries rounding error, and the recurrence decides whether that error grows on the way down. Measured on the trained models, on held-out text.

A fix

Anchor the bottom two states, and the reversible stack catches up

The embedding state has a norm near 1 while the states above it reach 30–1,150, so rebuilding it is a subtraction of large numbers that leaves only rounding. Storing s₀ and s₁ next to the top two states costs 3 MiB per sequence and removes the problem. Retrained on the same 50M tokens:
